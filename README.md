## 👤 About Me

I work at the intersection of **enterprise computing, applied AI, and open-source research** — building tools that make IBM Z mainframe systems understandable to modern engineering workflows, rather than treating them as legacy to be discarded. I'm an IBM Champion (2025 & 2026), an IBM Z Student Ambassador at the Superstar tier, and an Open Mainframe Project mentee under the Linux Foundation, researching AI-assisted mainframe modernization.

Alongside that, I publish applied ML research — from gradient-boosting ensembles for early medical prediction to reinforcement learning for ICU treatment policy — and build production-shaped software rather than proof-of-concept scripts: typed, tested, and documented. I'm completing my B.Tech in Computer Science at VIT Chennai (2027), and actively preparing for a mainframe engineering internship starting January 2027.

## 🧭 Engineering Philosophy

<table>
<tr><td width="34%"><b>Understand before you automate</b></td><td>Deterministic analysis first, generative AI second. You can't safely modernize a system you haven't actually parsed.</td></tr>
<tr><td><b>Legacy is under-tooled, not obsolete</b></td><td>Mainframes run the world's banking, healthcare, and aviation systems. The gap isn't the platform — it's the tooling around it.</td></tr>
<tr><td><b>Research should compile</b></td><td>A paper or whitepaper is a starting point. If it doesn't map to a working artifact eventually, it isn't finished.</td></tr>
<tr><td><b>Modular over monolithic</b></td><td>Small, composable, independently testable systems — over black-box, do-everything ones.</td></tr>
<tr><td><b>Open source is the credential</b></td><td>A public repo with tests and commits is worth more than a claim. Show the work.</td></tr>
</table>

## 🚀 Featured Projects

### 🤖 AI-Powered Mainframe Modernization Assistant
[![Repo](https://img.shields.io/badge/GitHub-View%20Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Edith-Stark06/ai-mainframe-modernization-assistant)
![Python](https://img.shields.io/badge/-Python%203.12-3776AB?style=flat-square&logo=python&logoColor=white)
![FastAPI](https://img.shields.io/badge/-FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![MIT](https://img.shields.io/badge/-MIT%20License-blue?style=flat-square)

An enterprise backend for parsing COBOL, JCL, and copybooks, building dependency graphs, extracting business rules, and eventually applying LLM-based modernization — built on **deterministic structural analysis first, generative AI second**, unlike tools that wrap an LLM directly around raw source. Currently: FastAPI service with intelligent file ingestion (ZIP upload, workspace inventory, file classification) and **265 automated tests** (Pytest, MyPy, Ruff, Black). Upcoming phases: COBOL lexer/parser, dependency graph construction, and a RAG-based modernization engine.
